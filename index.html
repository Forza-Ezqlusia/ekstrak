Baca detail: aturan nama dan cara kerja
Cara kerja: browser tidak dapat mengganti nama file secara langsung. Alat ini membuat salinan dengan nama baru, lalu menghapus file lama setelah kamu menyetujui prosesnya. Periksa pratinjau dan cadangkan file penting terlebih dahulu.

Mode Nama File: Lengkap memakai judul penuh (kata Ep, awalan dari nama file asli). Singkat mengubah judul yang terdiri dari 2 kata atau lebih menjadi huruf awal tiap kata, dengan huruf besar/kecil dipertahankan: Shuiro no Kamen - Ep 01 [720p].mp4 → SnK - 01 [720p].mp4. Angka utuh dipertahankan (Judul 2 → J2), judul satu kata dibiarkan, dan kata Ep dibuang (hasil: SnK - 01 [720p].mp4). Mode Singkat hanya menyentuh file yang memang cocok dengan pola di bawah atau sudah berbentuk Judul - Ep 01 maupun Judul - 01 [1080P] (tanpa kata Ep); file lain dibiarkan. Contoh: Dokidoki Little Ooyasan - 01 [720P].mp4 → DLO - 01 [720P].mp4. Awalan [NEW Release] dibuang dari judul. Jika dua file menghasilkan nama yang sama (misalnya inisial judul kebetulan sama) atau nama hasilnya sudah ada di folder, file itu ditandai ⚠ di pratinjau dan dilewati.

Pola yang dikenali:
• Otakudesu.net_OVL--Ep01_720p.mp4 → OVL - Ep 01 [720p].mp4. Jika bagian NAMA bukan sekadar nomor episode, hasilnya PREFIX-NAMA.mp4. Bagian [720p] hanya muncul jika resolusinya ada di nama asli.
• Alqanime_Overlord_BD_03_720p.mp4 → Overlord - Ep 03 [720p].mp4 (akhiran _BD/_WEB dibuang dari judul). Garis bawah di judul menjadi spasi: Alqanime_Shuiro_no_Kamen_03_720p.mp4 → Shuiro no Kamen - Ep 03 [720p].mp4.
• [Nimegami] Overlord 03 (720p).mp4 → Overlord - Ep 03 [720p].mp4 (spasi di judul tetap dipertahankan).
• [NekoPoi] Ep 01 720p.mp4 → Ep 01 [720p].mp4. Tag situs Otakudesu_, [NekoPoi], [nekopoi.care], nekopoi.care_, dan [NontonAnimeID]- di awal nama dibuang, spasi tetap dipertahankan.

Prefix khusus (dari kode Otakudesu): L9nM → Lv999, MSnS → Mato, MSnS.S2 → MatoS2, INN → Isekai, INN.S2 → IsekaiS2. Kode lain memakai tiga karakter pertama.

Perapian lain: teks -[nekopoi.care] di bagian mana pun nama file dibuang, dan [nekopoi.care] di akhir nama (sebelum ekstensi) juga dibuang. Nama tanpa spasi bergaris-bawah yang memuat _-_ (atau tag [nekopoi.care]) juga dirapikan: _Judul_Anime_-_03_[720P][nekopoi.care].mp4 menjadi Judul Anime - 03 [720P].mp4. Nama tanpa spasi yang memuat --- dirapikan: --- menjadi - dan tanda hubung lain menjadi spasi (Judul-Anime-node---01[1080P] menjadi Judul Anime node - 01[1080P]). Resolusi seperti 720p atau 1080p pada nama yang diubah dibungkus kurung siku menjadi [720p].

Baca detail: ekstrak ZIP & RAR dan Mode Nama File
Umum: arsip dicari di folder terpilih di atas (ikut opsi “Proses juga subfolder”). Semua berjalan di browser, tanpa unggah ke mana pun.

File .url: file shortcut internet (.url) tidak diekstrak, karena browser memblokir penulisannya. Contoh: Otakudesu.net-Situs Asli Download_Streaming_Anime_Lengkap.url.

Opsi ekstrak: “Pakai nama arsip sebagai nama folder” — jika arsip berisi satu folder induk, namanya diganti dengan nama arsip (tanpa subfolder tambahan); jika tidak, dibuat folder bernama arsip. “Rapikan nama file” mengubah nama file di dalam arsip sesuai Mode Nama File di bawah. Jika “Timpa” tidak dicentang, file yang sudah ada dilewati. “Hapus arsip” bersifat permanen dan hanya berjalan jika semua entri berhasil diekstrak.

Mode Nama File — Lengkap: memakai nama arsip sebagai awalan dan menulis Episode. Garis bawah pada nama arsip menjadi spasi (Shuiro_no_Kamen.zip → awalan Shuiro no Kamen). Contoh untuk arsip Overlord Season 2.zip:
• Otakudesu.net_OVL--Ep01_720p.mp4 → Overlord Season 2 - Episode 01 [720p].mp4
• Alqanime_Overlord_BD_03_720p.mp4 → Overlord Season 2 - Episode 03 [720p].mp4
• [Nimegami] Overlord 03 (720p).mp4 → Overlord Season 2 - Episode 03 [720p].mp4
• [NekoPoi] Ep 01 720p.mp4 → Overlord Season 2 - Episode 01 [720p].mp4

Bagian [720p] hanya muncul jika resolusinya ada di nama asli. Nama yang tidak cocok dengan pola mana pun tidak diubah. Aturan perapian lain (tag situs, ---, kurung resolusi) sama dengan tab File → Perbaiki Nama.

Mode Nama File — Singkat: judul dengan 2 kata atau lebih diubah jadi huruf awal tiap kata, huruf besar/kecil dipertahankan. Contoh: Alqanime_Shuiro no Kamen_03_720p.mp4 → SnK - 03 [720p].mp4. Angka utuh dipertahankan, judul satu kata dibiarkan, dan file yang tidak cocok pola dibiarkan.

Format arsip: ekstraksi ZIP mendukung metode Store dan Deflate. RAR: RAR5 didukung penuh, baik terkompresi maupun Store, termasuk arsip solid (dekompresi berjalan di browser dan memakai memori sebesar ukuran dictionary arsip). RAR4 hanya yang Store. RAR berpassword, multi-volume, atau RAR4 terkompresi akan dilaporkan gagal dan sebaiknya diekstrak dengan WinRAR/7-Zip.

Pilih file dari folder terpilih, lalu buat satu ZIP gabungan atau satu ZIP per file. File ZIP disimpan di folder yang sama.

Pilih folder di atas, lalu klik “Pindai file”.
Baca detail: kompres ke ZIP dan Mode Nama File
Umum: file dicari di folder terpilih di atas (ikut opsi “Proses juga subfolder”). Semua berjalan di browser, tanpa unggah ke mana pun. ZIP disimpan di folder yang sama.

Hasil: “Satu ZIP gabungan” membuat satu ZIP berisi semua file terpilih; “Satu ZIP per file” membuat satu ZIP untuk tiap file. Nama ZIP yang sudah ada tidak ditimpa (otomatis diberi akhiran “ (2)”). “Hapus file asli” bersifat permanen dan hanya berjalan setelah ZIP berhasil dibuat.

Metode: file video (.mp4, .mkv, dll.) sudah terkompresi, jadi mode Otomatis hanya mengemasnya tanpa kompresi ulang agar cepat dan ukuran tidak membengkak. ZIP yang dibuat kompatibel dengan Windows Explorer, 7-Zip, dan macOS; ZIP64 dipakai otomatis untuk file/arsip di atas 4 GB. Membuat file RAR tidak didukung (format tertutup); gunakan ZIP.

Rapikan nama file: hanya mengubah nama di dalam ZIP; file asli di folder tidak diubah. Aturan polanya sama dengan tab File → Perbaiki Nama.

Mode Nama File — Lengkap: hanya untuk ZIP gabungan. Nama ZIP menjadi awalan dan ditulis Episode. Contoh untuk Overlord Season 2.zip: [Nimegami] Overlord 03 (720p).mp4 → Overlord Season 2 - Episode 03 [720p].mp4.

Bagian [720p] hanya muncul jika resolusinya ada di nama asli.

Mode Nama File — Singkat: judul dengan 2 kata atau lebih diubah jadi huruf awal tiap kata. Contoh: Alqanime_Shuiro no Kamen_03_720p.mp4 → SnK - 03 [720p].mp4.

Baca detail: format hasil dan nama file
Ukuran dan format: bawaan 300 × 425 px, format JPG (bisa diganti WebP atau PNG, ukuran 1–4000 px). “Potong tengah” memenuhi seluruh bingkai tanpa gepeng, “Muat utuh” menambah latar putih, “Regangkan” bisa membuat gambar gepeng.

Nama file hasil: ID_Judul.jpg, sama seperti di tab Edit Data. Contoh: anime ID 8 berjudul Overlord I → 8_Overlord_I.jpg.

ID dari data.js: file data.js dipilih sekali di bagian paling atas Toolkit (dibaca di perangkat, tidak diunggah). Di sini cukup cari dan pilih anime. ID dan judulnya terisi otomatis, judul langsung dicari covernya, dan nama file memakai ID serta judul dari data.js. Jika Anda memproses lebih dari satu gambar untuk anime yang sama, nama diberi akhiran _1, _2, dan seterusnya. Menandai anime “tanpa thumbnail” membantu menemukan yang belum punya gambar.

Tanpa data.js: ketik ID sendiri di kolom “ID anime”. Untuk beberapa gambar, isi ID dipisah koma sesuai urutan: urutannya mengikuti urutan link. Judul diambil dari hasil pencarian atau nama file di link. Jika ID kosong atau kurang, awalannya ID_ sebagai penanda agar diganti.

Aturan judul: aksen dibuang, dan semua karakter selain huruf serta angka (termasuk spasi) diganti _.
Baca detail: sumber pencarian dan kalau gagal mengambil gambar
Pilih sumber lewat menu “Cari gambar dari” (judul dicari dari anime yang dipilih) (bawaan: semua sumber sekaligus; ganti pilihan untuk mencari dari satu sumber saja). Mode semua sumber mencakup AniList, Kitsu, MyAnimeList, HentaiHaven, dan Nekopoi. Pencarian AniList, Kitsu, dan MyAnimeList memakai Cloudflare Worker; HentaiHaven dan Nekopoi (18+) dibaca lewat Cloudflare Worker (/page), dengan proxy publik sebagai cadangan. LiveChart telah dihapus dari pencarian, thumbnail, dan pengisian jadwal. Beberapa situs memblokir pengambilan gambar langsung dari browser (CORS). Jika itu terjadi, alat ini otomatis mencoba lewat beberapa layanan perantara gambar publik (wsrv.nl, weserv.nl, photon, DuckDuckGo, corsproxy.io, allorigins, codetabs), yang berarti link gambar tersebut ikut dikirim ke layanan itu. Jika tetap gagal, buka gambarnya di tab baru, simpan manual, lalu gunakan fitur kompres/ubah ukuran lain.
